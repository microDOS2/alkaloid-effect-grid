# Plant Alkaloid Effect Grid

An interactive, evidence-labeled comparison matrix of 60 plant alkaloid substances across four subjective-effect classifications:

- **Stimulation / Energy**
- **Mood Elevation**
- **Calm / Anxiety Relief**
- **Enhanced Experience**

Each effect mark is labeled **Documented** (human studies), **Claimed** (traditional use / user reports), or **Disputed** (human evidence negative). Substances carry a safety tier (1 established safe · 2 borderline with caveats · 3 excluded), dependence rating, interaction note, and US/EU legal status.

**Live grid:** open `index.html` (or the GitHub Pages site once enabled).
**Print version:** `alkaloid_grid.pdf` (A4 landscape, tier-grouped).
**Companion report:** *Plant Alkaloids That Are Safe to Consume and Produce Positive Effects* (248 referenced sources).

## Updating

All content lives in **`data.js`** — one documented entry per substance (see the header comment in that file for the field schema). Edit, commit, reload: the webpage, filters, and stats update automatically. No build step.

## Disclaimer

Educational reference only. Not medical advice. Not a usage or dosing guide. "Claimed" effects have not been confirmed in human trials. Legal status changes rapidly — verify locally.
